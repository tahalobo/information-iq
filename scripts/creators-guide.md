# قسم «مبدعون عراقيون»: دليل الأدمن

موسوعة صغيرة للمبدعين العراقيين. لكل مبدع صفحة ثابتة برابط دائم (`creators/<slug>.html`) وشهادة ترحيب تُرسم داخل المتصفح.
الموقع بلا خادم ولا لوحة تحكم، فالنشر يدوي: تعدّل ملفاً واحداً ثم تبني الموقع.

| الشيء | مكانه |
|---|---|
| بيانات المبدعين (الملف الوحيد الذي تعدّله) | `scripts/creators.json` |
| صور المبدعين وأعمالهم | `assets/img/creators/` |
| الفهرس وصفحات المبدعين (تُولَّد، لا تعدّلها بيدك) | `creators/index.html` و `creators/<slug>.html` |
| القوالب | `scripts/build-pages.mjs` (قسم «مبدعون عراقيون») و `scripts/seo/creators.mjs` (التحقق من البيانات) |
| الشهادة | `assets/js/pages/creator.js` |
| نموذج الترشيح | `contact.html?type=creator` |

## إضافة مبدع جديد خطوة بخطوة

1. **خذ موافقته أولاً.** الصفحة علنية وتظهر في غوغل باسمه وصورته وروابطه. لا تُضف أحداً قبل أن يوافق هو نفسه
   كتابةً (رسالة في الدايركت أو تليغرام تكفي)، حتى لو رشّحه شخص آخر. احتفظ بالرسالة.
2. **جهّز الصور** وضعها في `assets/img/creators/`:
   - الصورة الشخصية: مربّعة، يُفضَّل 600×600، بصيغة JPG أو PNG أو WebP.
   - صور الأعمال: بنسبة 4:3 تقريباً، عرض 800 بكسل يكفي.
   - اسم الملف بحروف لاتينية وأرقام وشرطات فقط، مثل `ali-hassan.jpg` و `ali-hassan-work-1.jpg`.
3. **افتح `scripts/creators.json`** وانسخ سجلاً موجوداً داخل القائمة `creators` وعدّل حقوله (لا تنسَ الفاصلة `,` بين السجلات):

   ```json
   {
     "slug": "ali-hassan",
     "serial": 4,
     "published": true,
     "name": "علي حسن",
     "field": "رسام",
     "province": "بغداد",
     "city": "الكرادة",
     "bio": "جملة أو جملتان تعرّفان به. تظهر في البطاقة وفي نتائج البحث.",
     "about": ["فقرة أولى من التعريف المفصّل.", "فقرة ثانية."],
     "photo": "assets/img/creators/ali-hassan.jpg",
     "works": [
       { "title": "اسم العمل", "desc": "وصف قصير", "image": "assets/img/creators/ali-hassan-work-1.jpg", "url": "https://…", "year": 2026 }
     ],
     "links": [
       { "label": "إنستغرام", "url": "https://www.instagram.com/…" }
     ],
     "added": "2026-12-01",
     "consent": { "given": true, "date": "2026-11-30", "via": "رسالة على إنستغرام" }
   }
   ```

   | الحقل | الشرح |
   |---|---|
   | `slug` | اسم الرابط: حروف لاتينية صغيرة وأرقام وشرطات فقط. **لا تغيّره بعد النشر** لأنه رابط المبدع الدائم والمطبوع في شهادته. |
   | `serial` | رقم الشهادة التسلسلي (يظهر `IQC-0004`). خذ أكبر رقم موجود وأضف 1. لا يتكرر ولا يُعاد استعماله بعد حذف مبدع. |
   | `published` | `true` ليظهر. `false` يبقيه مسودة لا تُنشر. |
   | `name` و `field` | مطلوبان. المجال نص حر (رسام، مبرمجة، كاتب، مصوّر، صانع محتوى، موسيقي…). اكتب المجال نفسه بالصيغة نفسها لكل من يشتركون فيه حتى تجمعهم التصفية. |
   | `province` و `city` | المحافظة تُستعمل في التصفية. المدينة اختيارية. |
   | `bio` | نبذة قصيرة (حتى 400 حرف). |
   | `about` | فقرات التعريف المفصّل، كل فقرة نص مستقل. اختياري. |
   | `photo` | مسار الصورة الشخصية. إن تُرك فارغاً يظهر أول حرف من الاسم. |
   | `works` | الأعمال: `title` مطلوب، والباقي اختياري (`desc`، `image`، `url`، `year`). |
   | `links` | حسابات المبدع. تُقبل روابط `http` و `https` فقط. |
   | `added` | تاريخ الإضافة بصيغة `سنة-شهر-يوم`. يظهر في الصفحة والشهادة. |
   | `consent` | إثبات الموافقة: `given: true` بعد أن يوافق المبدع نفسه، مع التاريخ والطريقة. **بلا `given: true` لا تُنشر الصفحة.** |

4. **ابنِ الموقع:**

   ```
   node scripts/build-pages.mjs
   node scripts/seo-audit.mjs
   node scripts/security-audit.mjs
   ```

   إن كان في سجلٍّ خطأ (رابط غير صالح، صورة غير موجودة، موافقة ناقصة) يطبع البناء تنبيهاً يبدأ بـ `⚠ مبدعون:` ويتخطّى ذلك المبدع وحده.
   بطاقة المعاينة (التي تظهر عند مشاركة الرابط في واتساب وتليغرام) تُرسم تلقائياً باسمه وصورته.
5. **ارفع التعديلات** إلى `main` (الملف والصور والصفحات المولَّدة). ينشرها GitHub تلقائياً.
6. **أرسل للمبدع رابطه:**
   - صفحته: `https://iraqiempire.com/creators/ali-hassan.html`
   - شهادته مباشرة: الرابط نفسه مع `#certificate` في آخره. يفتح الشهادة بمقاسين: أفقية للطباعة والمشاركة، وطولية للستوري.

## تعديل صفحة أو حذفها

- **تعديل:** عدّل سجلّه في `creators.json` ثم ابنِ الموقع.
- **إخفاء مؤقت:** اجعل `"published": false`.
- **حذف:** احذف سجلّه من الملف واحذف صوره من `assets/img/creators/` ثم ابنِ الموقع. تُحذف صفحته وبطاقة معاينته تلقائياً.
  إن طلب المبدع الحذف فنفّذه دون تأخير (التزمنا بذلك في `privacy.html#creators` و `methodology.html#creators`).

## المبدعون التجريبيون

السجلات التي فيها `"demo": true` أشخاص غير حقيقيين لعرض الشكل فقط. صفحاتهم تحمل تنبيه «صفحة تجريبية» ولا تُفهرس في غوغل ولا تدخل sitemap.
**احذفهم قبل الإعلان عن القسم:** احذف السجلات الثلاثة من `creators.json` واحذف الملفات `assets/img/creators/demo-*` ثم ابنِ الموقع.
ولا تضع `"demo": true` في سجل مبدع حقيقي.

## الشهادة

ترحيب وتكريم رمزي: اسم المبدع، ومجاله، وتهنئة بانضمامه، وتاريخ الإضافة، ورقم الشهادة، ورمز QR يفتح صفحته، ورابطه مكتوباً.
ليست اعتماداً رسمياً أو مهنياً، وهذا مكتوب أسفلها. لا تُعدّل نصّها بما يوحي بغير ذلك.

## نموذج الترشيح

زر «رشّح نفسك أو رشّح مبدعاً» يفتح `contact.html?type=creator`. تصل الرسالة إلى كروب الفريق مثل بقية رسائل الموقع، وفيها: من المرشِّح،
واسم المبدع ومجاله ومحافظته ونبذته وروابط أعماله، والإقرار الذي وافق عليه.
ليظهر نوع الرسالة «ترشيح مبدع» في الكروب، أعد نشر `scripts/contact-form.gs` في Google Apps Script (Deploy ← Manage deployments ← New version).
وإن لم تُعد نشره تصل الرسالة كاملة أيضاً، لكن بعنوان «استفسار عام».
