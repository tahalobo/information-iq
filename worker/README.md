# تفعيل البحث العكسي داخل الموقع

أداة البحث العكسي تعرض النتائج داخل الموقع، **مجاناً وبلا مفتاح API وبلا بطاقة دفع وبلا حد شهري**.
المتصفح لا يستطيع سؤال محرك البحث مباشرة (قيود CORS)، لذلك نحتاج «وسيطاً» صغيراً مجانياً هو **Cloudflare Worker**.

```
الزائر ← موقعك (GitHub Pages) ← Cloudflare Worker ← بحث ياندكس بالصورة + زيارة الصفحات لمعرفة تواريخها
```

> **بدون هذا الإعداد** تبقى الأداة تعمل، لكن بقدرات أقل:
> - تبحث في أرشيف الإمبراطورية فوراً ومن دون أي رفع.
> - تعرض أزرار المحركات الخارجية بدل البحث داخل الموقع.

## بصراحة: ما حدود هذه الطريقة؟

- العامل يقرأ **صفحة نتائج ياندكس العامة** وليس واجهة رسمية. إن غيّر ياندكس شكل الصفحة أو طلب كابتشا من عناوين Cloudflare، يتوقف البحث مؤقتاً، ويعرض الموقع رسالة واضحة مع المحركات الخارجية. الإصلاح يكون في الدالة `readState` داخل `reverse-search.js`.
- Cloudflare Workers المجاني يسمح بـ **100 ألف طلب يومياً**. كل بحث يستهلك نحو 7 طلبات (بحث واحد + 6 دفعات تواريخ)، أي نحو 14 ألف بحث يومياً.
- لم يعد هناك سؤال مباشر لقاعدة مدققي الحقائق (كانت تحتاج مفتاح غوغل). بدلاً منه يبرز الموقع أي صفحة نتيجة تعود لموقع تدقيق حقائق معروف (مسبار، فتبينوا، AFP، Snopes…).

---

## النشر على Cloudflare (5 دقائق، بلا بطاقة)

1. سجّل مجاناً في https://dash.cloudflare.com
2. اذهب إلى **Workers & Pages ← Create ← Create Worker**:
   - سمّه `empire-reverse` واضغط **Deploy**.
   - اضغط **Edit code**، واحذف المثال، والصق محتوى الملف `worker/reverse-search.js` كاملاً، ثم **Deploy**.
3. (إلزامي) من **Settings ← Variables and Secrets** أضف:

   | الاسم | النوع | القيمة |
   |---|---|---|
   | `ALLOWED_ORIGINS` | Text | **إلزامي.** أصل موقعك بلا مسار، مثل `https://tahalobo.github.io` (لأكثر من أصل افصل بفاصلة). بلا هذه القيمة يرفض العامل كل الطلبات. القيمة مضبوطة مسبقاً في `wrangler.toml`. |

   هكذا لا يستطيع موقع آخر استخدام عاملك.
4. انسخ رابط العامل، وهو يشبه `https://empire-reverse.yourname.workers.dev`.

## الربط بالموقع (دقيقة)

في الملف `assets/js/config.js`:

```js
reverseSearchEndpoint: "https://empire-reverse.yourname.workers.dev",
```

ارفع التعديل، وافتح صفحة البحث العكسي. سيظهر زر **«ابحث الآن»**، وتظهر النتائج داخل الصفحة.

## التجربة على جهازك قبل النشر

```bash
node worker/dev-server.mjs
```

يشغّل العامل على `http://localhost:8787`. وعند فتح الموقع من `localhost` تستخدمه صفحة البحث العكسي تلقائياً دون تعديل `config.js`.

## ماذا يُرجع العامل؟

`POST /` مع `{ image: "data:image/jpeg;base64,…" }` أو `{ url: "https://…" }`:

- **pages:** الصفحات التي ظهرت فيها الصورة (العنوان، الرابط، النطاق، مصغّرة، رابط الصورة الأصلية وأبعادها).
- **sizes:** نسخ الصورة بأحجام أخرى.
- **similar:** صور مشابهة (ليست الصورة نفسها).
- **tags / text:** وسوم تصف محتوى الصورة، والنص المقروء فيها إن وُجد.

`POST /dates` مع `{ urls: [...] }` (حتى 8 روابط): يزور كل صفحة ويقرأ رأسها فقط ليستخرج **تاريخ النشر** واسم الموقع.
الموقع يطلب التواريخ على دفعات لأول 48 صفحة، فيرتّب الخط الزمني ويحدد **أقدم ظهور** أثناء وصولها.

الموقع يصنّف المصادر وحده: وكالات أنباء، ومواقع إخبارية، وجهات رسمية، ومدققو حقائق، وتواصل اجتماعي، وصور مخزّنة.

## الخصوصية

- تُرسل **نسخة مصغّرة** من الصورة (1280 بكسل كحد أقصى) إلى ياندكس للبحث فقط. الموقع يوضح ذلك للزائر تحت الزر.
- العامل لا يخزّن الصور. يحفظ نتيجة البحث فقط (JSON) لمدة 3 أيام، ومفتاحها هو بصمة الصورة.
- البحث في أرشيف الإمبراطورية يجري كله داخل متصفح الزائر.

## تحديث بصمات الأرشيف

يحدّث GitHub Action البصمات تلقائياً مع كل مزامنة لتليغرام. ولتشغيله يدوياً:

```bash
python scripts/build-image-index.py
```
